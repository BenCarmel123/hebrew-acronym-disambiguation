\section{Systems and Experimental Design}
\label{sec:systems}
The encoder ranks candidates; each LLM performs both generation and selection. Only the ranker receives task-specific supervised training. All LLMs get the same prompt for each task, and selection shows the candidates in the same seeded, shuffled order for every item. DictaBERT has 184 million parameters, compared with about 7B and 14B for the Qwen models; proprietary model sizes are not public.

\subsection{Supervised Hebrew candidate ranker}
DictaBERT is a pretrained Hebrew encoder \citep{shmidman2023dictabert}. Our implementation is a \emph{cross-encoder}: the marked sentence and one candidate are encoded jointly, so their tokens can attend to each other. A dropout layer and a linear head turn the pooled representation into a scalar score. Candidates are scored independently, and prediction chooses the highest score within the item's candidates.

For each training item, the reference candidate is positive and the other candidates are negative. The objective is binary cross-entropy on the pair scores, over $M$ sentence--candidate pairs:
\begin{equation}
\mathcal{L}=-\frac{1}{M}\sum_{j=1}^{M}\big[z_j\log p_j+(1-z_j)\log(1-p_j)\big].
\end{equation}
Here $p_j=\sigma(u_j)$ is the sigmoid of pair score $u_j$, and $z_j$ is 1 for the reference candidate and 0 otherwise. All model weights are updated with AdamW, a variant of the Adam gradient-based optimizer that applies weight decay separately from the gradient update.

Training uses dropout 0.1, learning rate $2\times10^{-5}$, pair batch size 16 and one epoch, keeping the checkpoint with the lowest development pair loss. The checkpoint was trained by one of the authors (B.C.) in Google Colab, starting from \texttt{dicta-il/dictabert}, with seed 43. The training code set this seed only after creating the model, so it did not fix the scoring head's initial weights.

For inference we reload the trained weights, including the scoring head, and verify them in full. Each pair joins the marked sentence and candidate with BERT special tokens, and long contexts are cropped to 256 tokens around the target. In test sentences the first occurrence of the acronym is marked automatically. The LLMs receive the full original sentence.

As a baseline without task training, we use pretrained DictaBERT as a similarity scorer: it encodes the marked context and each candidate separately and picks the candidate whose \texttt{[CLS]} vector is most similar to the context's. This baseline differs from the ranker in architecture as well as in training.

\subsection{Prompted language models}
The generation prompt, written in Hebrew, gives the original sentence and names the acronym separately, asking for its expansion in a few words without explanation. It supplies neither candidates nor the reference. The selection prompt adds the candidate list and requests one label, such as A or AA, with no extra text. Neither prompt includes worked examples. Every LLM received exactly the same prompt text for each item and task, verified from the saved requests, although chat templates and APIs differ.
