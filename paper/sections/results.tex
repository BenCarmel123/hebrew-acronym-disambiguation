\subsection{Held-out test results}
\label{sec:test-results}

\begin{figure}[t]

Table~\ref{tab:test-results} reports the single held-out evaluation on the
frozen, type-disjoint natural test population (\texttt{data/splits/test\_items.csv},
395 items), run once on 3 October 2026. Baselines, both DictaBERT arms and
both LLMs (generate and select, one request per item) were scored under an
identical item universe and the shared exact-match scorer; per-item records
are retained under \texttt{results/\{dictabert,dictabertx,qwen,gemini\}/}.

Free generation fails as scored for both LLMs: the overwhelming majority of
generated responses never produce the candidate's exact text, whether because
the model answers with a close paraphrase, over-explains instead of returning
a short phrase, or -- for Qwen specifically -- produces garbled,
mixed-script output unrelated to the prompt. Restricting the same models to
select from the fixed inventory closes most of that gap (Qwen: 6.8\% to
59.5\%; Gemini: 53.2\% to 93.7\%), directly answering whether a
general-purpose LLM already solves this task from context alone: not under
free generation, but yes once given the same candidate-constrained scaffold
the trained encoder uses.

The fine-tuned encoder (72.4\%) clearly exceeds both baselines and its own
untrained zero-shot variant, and clearly exceeds unconstrained LLM generation
for both LLMs -- a real, defensible result for task-specific fine-tuning over
naive prompting. It does not exceed Gemini under selection (93.7\%), the
strongest arm overall.
