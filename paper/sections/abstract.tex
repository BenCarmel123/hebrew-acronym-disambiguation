Hebrew acronyms are often ambiguous, and language models can resolve them either by generating an expansion or by selecting from candidate expansions. We evaluate both on a human-reviewed held-out test set of Hebrew sentences, most of them natural, whose acronym forms never appear in training, comparing seven LLMs with a pretrained Hebrew encoder. In the main comparison, the task-trained encoder reaches 71.7\% in candidate selection, competitive with local Qwen models (58.5--69.8\%), while the API models score higher (83.2--93.7\%). Selection scores exceed generation scores for all six main LLMs, but candidate access and scoring rules differ, so the gap does not isolate model ability. We report DictaLM separately because of an input-template limitation, distinguishing automatic generation, Ben's annotations, strict selection and a lenient decoding diagnostic. Human review illustrates limitations of automatic measurement without supporting a human ranking across models.
