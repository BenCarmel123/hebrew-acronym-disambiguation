Hebrew acronyms can have several meanings in context. We build a data and evaluation framework to compare free generation and candidate selection on the same occurrences, using prompted language models and a task-trained Hebrew encoder. The inventory includes ordinary expansions and conventional interpretations such as gematria. Exact test acronym strings are absent from the documented train/dev files; historical training inputs and pretraining exposure are not fully known. In the main comparison, the encoder reaches 71.7\% in selection, competitive with local Qwen models (58.5--69.8\%), while API models score higher (83.2--93.7\%). Selection scores exceed generation scores for all six main LLMs under the automatic metrics. Candidate access, reference wording and scoring differ together, so this gap does not isolate semantic ability. Known reference errors also limit fine-grained ranking. DictaLM is reported separately with an input-template limitation. The findings show why model choice, candidate access and reference design must be considered together in evaluating contextual acronym resolution.
