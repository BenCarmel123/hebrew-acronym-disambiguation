\begin{abstract}
A language model can interpret an acronym in a sentence by generating an expansion or by choosing from a supplied inventory. We study this distinction for Hebrew using the same marked occurrences in five systems: a fine-tuned DictaBERT candidate ranker, and generation and selection configurations of Qwen and Gemini. The comparison changes both candidate access and answer format; it does not isolate either factor. The current input files contain 2,829 training items and 62 natural development items, with substituted, natural and AI-authored training material kept identifiable. The development set contains 11 acronym types with one observed reference meaning per type, which limits what it can establish about contextual disambiguation. Selection has an implemented common evaluator; free responses await a final human judgment protocol. Saved development runs document complete DictaBERT selection and both Qwen tasks, with partial Gemini coverage. They support diagnosis, not final evaluation. This draft presents the methods and observed development limitations; final test results and conclusions remain pending.
\end{abstract}
